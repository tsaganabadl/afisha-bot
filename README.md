# Telegram-бот «Афиша»

Бот для подбора мероприятий в Москве по категории, дате и цене. Данные берет из открытого API KudaGo.

## Стек
* Python 3.11
* aiogram 3.x
* aiohttp
* Docker


## Структура
* `handlers/` — обработчики команд и кнопок
* `keyboards/` — клавиатуры
* `services/` — работа с API KudaGo и форматирование
